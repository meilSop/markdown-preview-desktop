## 如何编写这些规范

对于每个规范文件：

1. 记录项目**实际采用的约定**（而非理想化的做法）
2. 包含代码库中的**代码示例**
3. 列出**禁止使用的模式**及原因
4. 补充团队曾经犯过的**常见错误**

目标是帮助 AI 助手和新团队成员理解你的项目是如何运作的。
