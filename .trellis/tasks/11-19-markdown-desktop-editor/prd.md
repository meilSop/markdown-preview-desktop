# Markdown 桌面编辑器 MVP（Electron + Vue3）

## Goal

从零搭建一个个人自用的 Markdown 桌面应用：支持文件夹工作区浏览、多标签编辑、分栏实时预览、自动保存，以及代码高亮 / 数学公式 / 图表渲染和 HTML/PDF 导出。

## 背景决策（grilling 收敛结果）

| 决策点   | 结论                                                           |
| -------- | -------------------------------------------------------------- |
| 目标用户 | 个人自用，Windows 单平台                                       |
| 编辑形态 | 分栏实时预览（左源码 / 右预览），非所见即所得                  |
| 文件模型 | 文件夹工作区：侧边栏文件树（懒加载），支持新建 / 重命名 / 删除 |
| 保存策略 | 自动保存：编辑防抖 1.5s 后写盘，无脏状态弹窗                   |
| 标签     | 多标签页，tab 持有 path + content + dirty                      |
| 渲染     | markdown-it + highlight.js + KaTeX + Mermaid，预览防抖 250ms   |
| 主题     | CSS 变量亮暗双主题，跟随系统 + 手动切换                        |
| 导出     | HTML（渲染结果套模板）、PDF（webContents.printToPDF）          |
| 文件关联 | 不注册 .md 文件关联，不处理单实例启动参数                      |
| 分发     | electron-builder NSIS 安装包，无签名、无自动更新               |

## Requirements

### P0 — 骨架（本任务必须交付）

1. electron-vite + Vue3 + TypeScript + Pinia 脚手架，主 / 预加载 / 渲染三进程结构
2. 主窗口：侧边栏（文件树占位）+ 标签栏占位 + 分栏编辑区（源码 / 预览）
3. 打开单个 .md 文件 → 编辑 → 自动保存（防抖 1.5s）→ 预览实时刷新（防抖 250ms）
4. 预览渲染：GFM（表格 / 删除线 / 任务列表）+ 代码块 highlight.js 高亮
5. 亮色主题（CSS 变量体系，为暗色预留变量结构）

### P1 — 工作区与标签

6. 打开文件夹 → 侧边栏文件树（目录懒加载展开），支持新建 / 重命名 / 删除文件与文件夹（带确认）
7. 多标签页：切换、关闭、双击标签或拖拽分栏比例可调（布局手感从简）
8. 关闭标签 / 退出应用时若有未写盘变更，强制 flush 而不是丢弃

### P2 — 增强

9. KaTeX 数学公式（$...$ 与 $$...$$）
10. Mermaid 图表（```mermaid 代码块）
11. 导出 HTML（当前文件渲染结果套内联样式模板）与 PDF（printToPDF）
12. 暗色主题：跟随系统 + 手动切换，编辑器 / 预览 / Mermaid 联动换肤

### V4 — 标签页右键菜单（用户实测反馈，2026-11-19，附截图）

21. 标签页右键菜单：右键任意 tab 弹出菜单，支持：关闭、关闭其他、关闭右侧标签页、关闭左侧标签页、关闭已保存、关闭全部。语义约束：批量关闭前逐个 flush 脏 tab（关闭即保存并关闭，任一 flush 失败则中止整批并 toast 错误，不静默丢弃脏内容）；激活 tab 落到被关集合时由 removeTabs 既有回落逻辑接管；菜单项禁用规则：关闭右侧（锚点是最后一个 tab）、关闭左侧（锚点是第一个 tab）、关闭其他（仅剩 1 个 tab）、关闭已保存（无非脏 tab）时置灰

### V5 — 滚动条样式（用户实测反馈，2026-11-19，附截图）

22. 全局滚动条样式：去掉 Chromium 默认滚动条的实心轨道背景与上下箭头按钮；滑块改半透明中性灰（深浅主题与浅色预览区背景下均可见），hover 加深；圆角细长条，交叉角也透明。覆盖所有滚动区域（文件树 / 编辑器 CodeMirror / 预览区 / 标签栏横向滚动）

### V6 — settings 持久化失效根治（用户实测反馈，2026-11-19）

23. 症状：打开的项目、主题色、布局模式重启后全部丢失；V6 加 toast 后切设置必报「设置保存失败」。最终根因（主会话诊断反转，以证据为准）：persist 载荷的 roots 字段直接取 Pinia reactive Proxy 数组（this.roots）传给 ipcRenderer.invoke，V8 structured clone 对 Proxy 抛 DataCloneError → 写调用从未到达主进程（settings.v2.json 一直不存在；同期同目录 Chromium 文件与探针新文件写入均正常，此前误判的亿赛通文件锁不成立）。时间线佐证：16:36 = P2 时代最后一次成功写（载荷无 roots），V2 加 roots 后全部失败。修复：persist 载荷解包为普通数组（[...this.roots]）；全仓排查其余 invoke 传参无 Proxy；主进程迁移读取增强：v2 存在但缺 theme 字段（非应用写入的合法配置）时视同不存在，仍回读旧 settings.json 迁移

### V7 — 活动条与全局检索（用户需求，2026-11-20，附截图）

24. 工作区左侧新增活动条（ActivityBar，窄列图标菜单）：两个视图入口——资源管理器（默认选中，即现有文件目录树）与全局检索；选中态高亮（左侧 accent 边条 + 图标着色），切换时侧栏内容区对应切换
25. 全局检索（与 VSCode 保持一致）：关键词搜索（区分大小写 / 全词匹配 / 正则 三开关）+ include/exclude 文件过滤（逗号分隔 glob）+ 结果按文件分组树（文件名 + 命中数，展开显示行号 + 命中高亮）+ 点击结果自动打开该文件并跳转到命中行 + 替换全部（替换前自动保存已打开文件，替换后刷新已打开 tab 内容）；主进程递归搜索：默认排除 node_modules/.git/dist/out 等目录，仅扫文本类扩展，超大文件跳过，结果上限防卡顿；新 IPC：search:in-workspace / search:replace

### V8 — 检索与交互优化六项（用户实测反馈，2026-11-20，附截图）

26. 检索面板「替换全部」文字按钮改为替换图标按钮，hover 显示 tooltip「替换全部」

31. 文件树跟随激活 tab：打开/切换文件时，左侧目录自动展开其所有父节点、高亮该文件节点并滚动到可见（reveal in tree）

33. 查找面板两处体验修复（用户实测反馈，附标注截图）：①左侧展开/收起 chevron 按钮展开时高度自动撑开——改为左侧竖条贯穿两行（align-self stretch，点击整列切换展开，VSCode 同形态）；②查找框聚焦后按回车自动跳下一个匹配——现状被 IME 守卫的 keyCode === 229 检查误伤（中文输入法开启时即使直接输英文字母 Enter 的 keyCode 也常为 229），改为 compositionstart/compositionend 状态机 + ev.isComposing 判定（拼音候选上屏回车仍吞，非组合状态回车必跳）；③导航/替换后焦点保持调用方原处（移除 gotoFind/replaceOne 尾部 v.focus()），查找框可连续回车跳转；④全局检索输入框清空时同步清结果列表并递增序号使在途响应过期（旧结果回填根因）；⑤包含/排除 glob 输入框默认隐藏，替换行末尾「...」三点按钮切换展示（VSCode「切换搜索详细信息」同款）

## 明确不做（v1）

- 外部文件修改监听（chokidar）、双向链接、崩溃恢复快照；全局搜索已由 V7 需求 25 覆盖，不再属于本条
- 大文件（>1MB）专项优化
- .md 文件关联、单实例锁、自动更新、安装包签名
- 跨平台（macOS / Linux）适配

## 约束

- 平台：Windows（开发与目标平台）
- 安全基线：`contextIsolation: true`、`nodeIntegration: false`，渲染进程只能通过 preload 暴露的 IPC API 访问文件系统
- 所有文件 IO 必须发生在主进程
- 渲染层不允许直接 import 任何 Node API
